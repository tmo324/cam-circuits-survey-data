# Contributing

Contributions that correct metadata, add missing CAM designs, or improve
reproducibility are welcome.

## Data changes

1. Preserve data/raw/cam_survey_master.xlsx as the canonical source.
2. Record area in square micrometers, process node in nanometers, and search
   energy in femtojoules per bit per search.
3. Keep manuscript and proof reference numbers in separate fields.
4. Run python analysis/generate_all.py.
5. Inspect the regenerated figures, then include the data change and generated
   outputs in the same pull request.

Do not hand-edit data/processed/cam_cell_designs.csv. It is generated by
analysis/prepare_data.py.

## Figure changes

Hand-drawn figures should be edited in their Draw.io source files. Exported
PNGs belong in figures/published only when they represent a verified
paper-facing version. Data plots belong in figures/generated and should be
changed through their Python scripts.

## Table changes

Update the corresponding CSV in data/processed, then run
python analysis/generate_tables.py. Tables II and III also depend on the
schematic panels under tables/assets.

## Validation

Before submitting a change, run:

~~~bash
python -m py_compile analysis/*.py
python analysis/generate_all.py
~~~

The validation step checks expected files, Draw.io XML validity, dataset row
counts, and a known normalization value.
