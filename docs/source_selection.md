# Source selection and renaming

The original working folder was left unchanged. This repository is a curated
sibling copy.

## Retained

- CAM Survey.xlsx became data/raw/cam_survey_master.xlsx.
- The main sheet export became data/raw/cam_survey_main_export.csv.
- AI Application Papers.xlsx became data/raw/cam_applications_sources.xlsx.
- All nine Draw.io files were retained byte-for-byte and renamed under
  figures/source.
- Final manuscript figure exports and table schematic panels were retained
  with paper-numbered names.
- The final manuscript BibTeX library became references.bib.

## Replaced

The four notebooks were replaced by the four clean analysis scripts listed in
the main README. The notebooks themselves are not shipped because their output
cells, repeated experiments, package-install commands, and legacy missing CSV
paths are not needed for reproduction.

## Omitted

- Draft DOCX manuscripts and revision documents.
- A desktop screenshot.
- Redundant or superseded workbooks such as the old search-energy, trends,
  reference-update, and empty cell-design table files.
- Old and unused figure exports from the final-submission directory.
- Author biography photographs and the article PDF.

These omissions do not remove a source needed for any numbered paper artifact.
